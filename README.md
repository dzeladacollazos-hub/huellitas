# Huellitas 🐾

MVP de tienda online de accesorios personalizados para perros y gatos (pecheras, collares, correas, placas y juguetes).
Proyecto Integrador PA2 – Diseño de Negocios Digitales (ISIL).

**Integrante:** Diego Zelada Collazos

## Funcionalidades
- Catálogo dinámico con filtros por mascota (perro/gato), categoría y buscador.
- Carrito de compras con contador, cantidades y guardado en `localStorage`.
- Personalizador de placas y collares con vista previa en tiempo real.
- Checkout con validación de formulario, cálculo de envío (Olva Courier / Shalom) y medios de pago (Yape, Plin, Visa-Niubiz, Culqi, contraentrega).
- Botón flotante de WhatsApp, detección de ubicación para sugerir el envío y código QR con cupón.

## Tecnologías
HTML5 semántico · CSS3 (Flexbox y Grid) · JavaScript ES6
